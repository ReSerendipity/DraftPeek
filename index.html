DraftPeek 撰码轻览

一款现代、轻量的 Android 代码查看与编辑器，基于 Jetpack Compose 与 sora-editor 构建，支持 TextMate 与 Tree-sitter 语法高亮。

核心特性

多标签编辑与语法高亮
Markdown 实时预览（KaTeX / Mermaid）
LSP 智能补全（实验性）

快速开始

fun main() {
    val app = DraftPeek.init()
    app.open("main.kt")  // 开始阅读代码
}
