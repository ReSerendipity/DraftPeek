# 覆盖率爬坡计划（feature/editor + feature/browser，90 天）

> 建立于 2026-10-15（任务 DraftPeek-v29-remediate，落地《测试 Flash 报告》P1-1）。
> 依据：`coverage-baseline.json` 实测 feature/editor 4.01%（阈值 3.6）、feature/browser 2.21%（阈值 1.9）、core/ui 0.92%（阈值 0.8）——门禁防回归但不驱动增长。
> 口径与规则：阈值单一来源 `coverage-baseline.json`；棘轮只升不降；实测上升后按 `docs/CODING_STANDARDS.md` §7.2「新实测 ≈90%」规则**同批**上调；measured_pct 以 CI 产物为准（`coverage-baseline.json` notes 2026-10-07 补正条目）。
> 负责人：留空待认领（本计划为建议排期，非承诺）。

## 方法论（复制 settings 模式）

settings 模块在阶段 5 迁移中验证过的可复制路径（`coverage-baseline.json` notes 2026-10-06 各批）：

1. 每批迁移/拆分一个 UI 屏（数百行指令量级），保持行为不变；
2. 迁移同批为该屏补 RoundTrip 测试（setter/getter JSON 序列化往返、状态机流转），并保持 `isIncludeNoLocationClasses = true`（Robolectric 对 JaCoCo 不可见的教训，见 GOTCHAS #DP-09，本地文档）；
3. 实测显著上升时同批上调 `threshold_pct`（90% 规则），棘轮只升不降；
4. 分母控制：迁移会让无测试的 UI 指令进入分母——先补测试再迁屏，避免实测击穿阈值（2026-10-06 第二批教训：分母 8888→16232 曾致实测一度 14.05%）。

## 批次排期（建议 6 批 / 约 90 天）

| 批次 | 对象 | 动作 | 预期实测区间 | 棘轮动作 |
|---|---|---|---|---|
| E1 | feature/editor 设置类偏好 RoundTrip（editorThemeId / markdown 主题 / 自动配对等） | 补 Repository 风格 RoundTrip 测试 | 4.01% → 8~12% | 阈值 3.6 → 新实测 ≈90% |
| E2 | feature/editor EditorViewModel 状态机纯逻辑（标签/滚动/校验） | 状态流转测试 | +3~5pt | 同上 |
| E3 | feature/editor SoraEditorWrapper 桥接层纯函数（光标/选区映射） | 抽纯函数 + 测试 | +2~4pt | 同上 |
| B1 | feature/browser FileBrowserViewModel 排序/书签 JSON 往返 | RoundTrip（对齐 settings 模式） | 2.21% → 8~12% | 阈值 1.9 → 新实测 ≈90% |
| B2 | feature/browser InternalFileListContent 渲染分支（虚拟目录/排序） | Robolectric 渲染断言 | +3~5pt | 同上 |
| B3 | core/ui 高价值逻辑下沉（Brand 组件外的纯逻辑） | 逻辑下沉 + 测试 | 0.92% → ≥3% | 阈值 0.8 → 新实测 ≈90% |

## 验收口径

- 每批：跑 `./gradlew :feature/editor:testDebugUnitTest :feature/browser:testDebugUnitTest jacocoTestReport` 后，以 **CI 产物** INSTRUCTION 实测回填 `measured_pct`，并按 90% 规则上调 `threshold_pct`（同批提交，不许只升实测不升阈值）；
- 90 天终态目标：feature/editor、feature/browser 实测 ≥ 15%，core/ui ≥ 3%；提前达成的批次转为 browser/editor 交叉回归补强；
- 任何一批实测击穿阈值即 CI 红 → 按棘轮规则正向解决（补测试），禁止下调阈值。

## 风险与边界

- 全部工作为 JVM/Robolectric 单测，不引入新依赖；模拟器腿不在本计划内（属仪器化矩阵）。
- 指令分母随迁移增长：每批先补测试后迁屏（2026-10-06 第四批教训）。
- 本计划不改变 `coverage-baseline.json` 现有阈值；阈值只随实测上调。
