## 登记条目

### LEDGER-001 依赖倒置：core:domain 不得依赖 core:data（T1）

- 背景：85 分评估报告 T1（历史归因，正文仅本地）——domain 与 data 有 9 组同名 usecase 分居两处，架构边界名存实亡。
- 决议：接口与 model 上移 core:domain；core:data 反向依赖 domain 并做 entity↔model 映射。
- 落点：`.github/scripts/check_domain_boundary.py`（由 `.github/workflows/structure-guard.yml` 的 `layout` 必需检查执行）；`core/domain/`、`core/data/`。
- 状态：已落地（守卫在库）。

### LEDGER-002 巨型屏幕拆分与行数上限门禁（T2）

- 背景：FileBrowserScreen.kt 曾超 2,000 行，UI 单文件失控、改动牵一发动全身。
- 决议：按 ActionDialogs/Content 模式拆分；ui/sora 目录设 2,000 行硬上限并入必需检查，豁免清单显式为空。
- 落点：`.github/scripts/check_file_line_limit.py`（docstring 记录拆分史）；`feature/browser/src/main/java/com/draftpeek/feature/browser/ui/`。
- 状态：已落地；余量监控见《架构技术债 Flash 报告》P1-3（FileBrowserScreen 1,743 行 / EditorScreen 1,501 行，距上限 <15%）。

### LEDGER-003 ABI 裁剪：移除 x86、保留 x86_64（T7）

- 背景：安装包体积治理；真实设备 x86（32 位）占比可忽略。
- 决议：`ndk.abiFilters` 仅保留 arm64-v8a / armeabi-v7a / x86_64；x86_64 保留供 CI macrobenchmark 使用。
- 落点：`app/build.gradle.kts`（ndk 注释）；`docs/RELEASE_CHECKLIST.md` §5（production release APK ≈35.2MB 体积基线，异常 ≥+15% 须在 Release 说明注明）。
- 状态：已落地。

### LEDGER-004 覆盖率门禁「无数据即绿」根治与实测基线重置

- 背景：JaCoCo 报告链路历史性静默失效（SKIPPED 仍 BUILD SUCCESSFUL），旧覆盖率目标从未被真实数据验证。
- 决议：2026-09-05 修复报告产出链路；2026-09-29 重置为实测棘轮（INSTRUCTION 口径，阈值 ≈ 实测 90%，只升不降；报告缺失即失败）。
- 落点：`coverage-baseline.json`（阈值单一来源，notes 全程记录口径与重标规则）；`scripts/check_coverage_gate.py`；`docs/CODING_STANDARDS.md` §7.2。
- 状态：已落地；UI/feature 层爬坡计划另行登记入本目录（见后续条目）。

### LEDGER-005 Server CI (Python) 分级裁决

- 背景（2026-10-14）：Server CI 是否升为分支保护必需检查。
- 决议：维持非必需；以「有主的本地阻断式门禁」替代——改动 `server/**` 提交前必须 `cd server && pytest tests -q` 全绿，权威条目在 `docs/README.md`「Server 改动验证门禁」。
- 落点：`docs/ci/branch-protection.json`（contexts 三项）；`.github/workflows/main-verify.yml`（CONTEXT_OWNERS）；`.github/workflows/server-ci.yml`（PR 档全量触发、push 档带 paths 过滤）。
- 状态：已裁决，并经 live 只读实测对齐（`python scripts/apply_branch_protection.py` 无参只读报 [OK] 无漂移）。

### LEDGER-006 Gradle wrapper 工具链成套刷新

- 背景：wrapper jar 与脚本模板落后于 8.14.3 发行线；脚本仍为 `-jar` 直调旧模板。
- 决议：成套刷新——脚本模板改 CLASSPATH/-classpath 调用、properties 增 networkTimeout=10000 与 validateDistributionUrl=true、wrapper jar 48,966B→43,764B（双侧结构核验为真 Gradle wrapper jar），distributionUrl 保持 gradle-8.14.3 不变。
- 落点：基线快照提交 8254820（分类摘要 B 类）；`gradlew`、`gradlew.bat`、`gradle/wrapper/gradle-wrapper.properties`、`gradle/wrapper/gradle-wrapper.jar`。
- 状态：已落地。

## 新增决议登记流程

1. 新决策 → 本台账新增条目（LEDGER-NNN，编号递增不复用）；需要长期约束的同步写 ADR（`docs/adr/`）。
2. 涉门禁 → 与 workflow/脚本同批提交，条目「落点」给出库内链接。
3. 涉及必需检查变更 → 同步 `docs/ci/branch-protection.json` 与 `.github/workflows/main-verify.yml`（三处同步约定，见 `docs/README.md`「Server 改动验证门禁」节），并由 owner 授权执行 `python scripts/apply_branch_protection.py --apply` 写回远端。
