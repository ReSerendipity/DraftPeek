## 📌 第 2 部分：各报告核心要点汇总

### 2.1 编辑器内核（SoraEditor / Klyx / Squircle CE / AndroidIDE）
- **sora-editor**：83 色槽完整主题体系；诊断指示 API（`setDiagnostics` + `DiagnosticRegional`，WAVY_LINE 波浪线 + Tooltip）；StickyScroll 粘性滚动；Minimap 缩略图（@Experimental）;5 种可替换内建组件（`replaceComponent(EditorTextActionWindow.class,…)` 代替不存在的 `setTextActionWindow`）；TreeSitter 增量解析（包名 `editor.ts`，非 `langs.ts`）；`editor-lsp` 模块。
- **Klyx**：M3→sora 40+ 配色完整映射（`colorScheme.kt`）；LSP 端到端（LspManager + LspClient + LspLanguage + 诊断装饰器）；脏标记 debounce(500ms)+baseline 对比；EditorStateRegistry（@Single + ConcurrentHashMap）；DataStore JSON 序列化；CompositionLocal 批量 provide；HorizontalPager 多标签。
- **Squircle CE**：Git UI 5 屏矩阵（Commit/Push/Pull/Checkout/Fetch）；撤销栈持久化（CacheManager）；拖拽重排标签 + 触感反馈；主题 JSON 外部化（darcula.json）；跨模块事件总线；多文档状态机（DocumentState）；SearchPanel（regex/matchCase/wordsOnly）；快捷键路由表（24 个 Shortcut）。
- **AndroidIDE**：TreeSitter 增量语法分析；诊断标记 + DiagnosticRegion 映射；ILspEditor 接口分离；会话恢复（OpenedFilesCache.json）；TreeSitterLanguageProvider 注册表；内存保护上限（MAX_DIAGNOSTIC_FILES=10、MAX_PER_FILE=20）；IDEColorScheme JSON。
- **CodeAssist**：后端无关 DOM 模型 + Rope 文本存储（增量更新、多视图同步、线程安全）；非 LSP 语言后端；增量构建（无 Gradle daemon）。

### 2.2 代码能力增强（编码检测 / 性能 / 搜索）
- **920 Text Editor**：Mozilla UCD 编码检测（C NDK，60+ 编码）；多标签"自动复用空白标签"策略；语法高亮 span 复用池（免 GC）；Undo/Redo 容量上限 + FIFO 淘汰（MAX_SIZE=512KB）；大文件高亮阈值保护（400KB）；高亮死循环防护标志；语法配置外置。
- **Markor**：flexmark 扩展配置 + 静态单例下拉优化；条件式离线资源注入（KaTeX/Prism/Mermaid 按需）；标题行号映射（预览↔编辑器跳转，LineNumberIdExtension）；CRC32 内容变更检测；FileObserver 文件夹自动刷新 + 300ms 防抖；YAML Front Matter 模板变量；Beamer 演示模式；文件级 AES-256-GCM（.jenc）。
- **DiffEngine**：java-diff-utils 4.12（Myers，OOM 防护，5 千行限制），性能为自研 8-10 倍。

### 2.3 Markdown 渲染（compose-rich-editor / KMP-Markdown / OpenNote / multiplatform）
- **compose-rich-editor**：富文档树模型 + HTML/Markdown 双向解析 + Undo/Redo + Trigger 系统。
- **KMP-Markdown**：流式渲染、增量解析（DirtyRegionTracker/NodeReuser）、AST stableKey 用起始行号而非 contentHash 以解决流式渲染闪烁。
- **OpenNote-Compose**：Lite/Standard 双模式、CommonMark/GFM、LaTeX、Mermaid、大纲、Room 存储、异步解析。
- **multiplatform-markdown-renderer**：StreamingMarkdownState、顶层 Composable、元素组件体系、图片懒加载。

### 2.4 笔记/协作（Joplin / HedgeDoc / Logseq / AppFlowy）
- **Joplin**：monorepo + 共享核心引擎 + 多端 UI 壳；SQLite 驱动抽象；FTS4 全文检索；端到端加密（E2EE）与多云同步；外部编辑器监听。教训：借鉴**架构**而非照搬代码。
- **HedgeDoc**：Yjs + WebSocket 实时协作；CodeMirror 6 扩展架构；编辑/渲染双窗格同步滚动；工具栏格式化封装；状态栏；目录大纲。（AGPL，以借鉴设计为主）
- **Logseq**：本地优先大纲笔记；双向链接/块引用；块级数据库；双向链接、@提及为 DraftPeek 未实现能力。
- **AppFlowy**：CRDT 协同（结合 CRTD 数据模型）；模块化架构。

### 2.5 官方 Best Practice（nowinandroid / sunflower / compose-samples）
- **nowinandroid**：Material3 adaptive 布局（自适应列表-详情、折叠屏）、类型安全导航、分层架构、design system。
- **sunflower**：Compose + Room 数据库样例、协程绑定生命周期的数据驱动 UI。
- **compose-samples**：官方组件/性能/Lazy 列表规范；`key` 用主键、`expectNoEvents()` 等规范（已沉淀进 AGENTS Gotcha #20/22）。

### 2.6 Termux 生态
- **termux-app**：分层 Xterm 仿真（terminal-emulator / terminal-view / 主应用三层）；多会话管理；Bootstrap（pkg 安装）；Intent 命令执行；SAF；Toolbar。建议复用 terminal-emulator/view（Apache-2.0）+ Kotlin 协程重构 I/O。
- **termux-api**：TermuxApiReceiver 广播路由 + Unix Socket 通信 + 35+ 系统 API 封装（Dialog/Clipboard/Battery…）；权限管理。
- **termux-boot**：开机自启机制（BootReceiver）。
- **termux-tasker**：**Tasker 插件协议**（本地广播/服务绑定，供第三方自动化调用 App 能力）。
- **termux-float**：悬浮终端窗口。
- **termux-styling**：终端配色/样式主题。

### 2.7 AI 助手（gpt-runner）
- LangChain + OpenAI/Anthropic + Monaco 集成；AI 预设文件系统；文件上下文注入（LOC 选取）；CLI/Web/VSCode 多形态；流式对话、工具调用。
