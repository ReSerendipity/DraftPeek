# DraftPeek 隐私政策

**生效日期**：2026-08-12 ｜ **版本**：v1.0

DraftPeek 是一款本地优先的 Android 代码/文本编辑器与终端工具。我们遵循"本地处理、最小收集"原则，本政策说明数据处理方式。

## 1. 我们收集的数据

**本应用不收集、不上传任何个人信息。** 所有数据默认仅存储在您的设备本地：

| 数据类型 | 处理方式 | 存储位置 |
|---|---|---|
| 您编辑的代码/文本文件 | 仅本地读写，不上传 | 设备本地（您指定的目录） |
| FTP/SFTP 连接凭据 | 本地加密存储（AES-256-GCM），仅用于您主动发起的连接 | 设备本地数据库 |
| 应用设置与统计数据 | 本地存储（Room/SQLCipher 加密） | 设备本地 |
| 终端会话与命令记录 | 本地运行，不上传 | 设备本地 |

## 2. 权限说明

- **网络权限**：仅用于您主动使用的功能（GitHub 仓库导入、FTP/SFTP 远程连接、LSP 语言服务器）。我们不会在后台访问网络。
- **通知权限**：仅用于安全状态提醒（可选）。
- **应用可见性查询**：仅在您主动使用分享/跳转相关功能时按需声明，不读取其他应用数据。

## 3. 安全措施

- 数据库使用 SQLCipher 加密；敏感凭据使用 AES-256-GCM 加密存储；
- 终端命令执行经过参数化校验与危险命令识别，防止命令注入与误操作；
- APK 使用 R8 混淆与签名校验，防止篡改。

## 4. 第三方服务

- **GitHub**：您主动使用"仓库导入"功能时，代码将发送至 GitHub 服务器，受 [GitHub 隐私政策](https://docs.github.com/privacy) 约束；
- **LSP 服务器**：按您配置的服务器地址连接，请自行确认对方政策；
- **Google Play Integrity**：用于设备完整性验证，由 Google 处理，见 [Google 隐私政策](https://policies.google.com/privacy)。

## 5. 数据删除

卸载应用或清除应用数据即删除全部本地数据。FTP/SFTP 凭据可在设置中随时删除。

## 6. 政策更新

本政策如有变更，将在应用内与本页面同步更新并标注版本号。
